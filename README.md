## 🧱 How I like to ship

1. **Small, tested changes**: unit tests run on every build.
2. **Quality gates**: static analysis fails the pipeline before bad code reaches an image.
3. **Reproducible builds**: multi-stage Dockerfiles, versioned images in a registry.
4. **Declarative deployment**: Kubernetes manifests in the repository, with probes and autoscaling from the start.
5. **Observable**: metrics exposed for Prometheus so problems show up before users report them.
